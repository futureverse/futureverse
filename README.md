# futureverse: Install 'Futureverse' in One Go <img border="0" src="man/figures/logo.png" alt="The 'futureverse' hexlogo" align="right"/>


## Installation
R package futureverse is available on [CRAN](https://cran.r-project.org/package=futureverse) and can be installed in R as:
```r
install.packages("futureverse")
```


### Pre-release version

To install the pre-release version that is available in Git branch `develop` on GitHub, use:
```r
remotes::install_github("futureverse/futureverse", ref="develop")
```
This will install the package from source.
